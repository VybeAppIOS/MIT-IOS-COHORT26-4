## 2. Team rules
- Branches: `<initial>/<task-id>-<short-name>`, e.g. `t/sc-d1-discover-map`. Short-lived.
- Nothing is pushed to main. Everything goes through a pull request. Squash-merge.
- PR: about 300 lines max. Title "<task id>: what it does". Description: how to test, screenshot, which AI,
  pasted `check.sh` output, and "In my own words" (3 to 5 sentences).
- Lohitaksh reviews every PR and asks two "why" questions.
- Done = `AGENTS.md` section 6 (builds, runs, loading/empty/error, Theme tokens, previews, ViewModel test,
  author can explain every line).
- Stand-up 9:30 daily. Merge windows 13:00 and 19:00. Push unfinished work by 21:00.
- Never paste passwords, keys or personal data into any AI.
- Start each AI task with: "Read AGENTS.md and the task <ID> in docs/tasks/. Plan only; wait for my OK."
